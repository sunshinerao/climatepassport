# 管理后台证书中心服务端异常修复

## 需求解读
管理后台点击“证书中心”后，页面出现服务端异常页，需要让证书中心在存在异常数据时也能稳定渲染，避免单条脏数据导致整个页面崩溃。

## 修改方法
在证书中心服务端页面中加入防御性兜底，不再直接假设证书签发记录一定带有完整的关联对象，而是为缺失的证书名称、分类和持有人信息提供安全默认值。

## 修改内容
- 修改 [apps/passport-web/app/[locale]/admin/certificates/page.tsx](apps/passport-web/app/%5Blocale%5D/admin/certificates/page.tsx)，为缺失的证书定义、分类和持有人名称增加兜底文案。
- 保持原有查询和展示结构不变，只降低脏数据导致的 SSR 崩溃风险。

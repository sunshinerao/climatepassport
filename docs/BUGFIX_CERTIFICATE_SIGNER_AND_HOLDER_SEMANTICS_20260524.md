# BUGFIX_CERTIFICATE_SIGNER_AND_HOLDER_SEMANTICS_20260524

## 需求解读
- 签发审计中应保存签发人的可识别 ID，而不是只依赖展示文本。
- 证书上的 `signer` 应作为展示字段，由模板配置决定显示内容。
- 签发证书时，证书持有人应使用管理员在签发页输入的信息，而不是自动回退到收件人姓名。

## 修改方法
- 将模板渲染配置扩展为独立的 `signerName` 字段，并让预览与正式签发统一读取该配置。
- 在单个签发表单中增加显式的“证书持有人”输入，并把它同步进预览与签发请求。
- 保持现有审计字段 `approvedBy` 作为签发/审批人的可识别 ID 存储位置。

## 修改内容
- 模板配置编辑页新增 `signerName` 配置输入，并在保存与预览请求中透传。
- 模板预览接口和正式签发接口改为优先使用配置中的 `signerName` 生成证书变量 `signer`。
- 单个证书签发页新增证书持有人输入，编辑已签发记录时可回填该值。
- 手动变量输入区不再把 `holderName` 当作普通可见变量重复展示。
- 已通过现有测试套件验证回归。

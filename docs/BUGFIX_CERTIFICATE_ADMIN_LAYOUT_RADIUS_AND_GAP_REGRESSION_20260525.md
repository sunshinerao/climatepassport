# 需求解读
管理后台证书中心所有页面出现区块圆角丢失、区块间距消失的问题，需要定位真实根因并恢复原有统一视觉结构。

# 修改方法
检查证书中心样式入口 `certificate-admin.css` 的根规则链路，重点核查 `.cpca` 根容器（变量、网格间距、卡片圆角依赖）是否被正确解析。发现文件头注释语法破损后，先修复语法，再验证解析和错误状态。

# 修改内容
- 文件：`apps/passport-web/app/styles/features/certificate-admin.css`
- 根因：文件首部注释缺失开头 `/*`，导致 `.cpca` 根规则解析链路异常。
- 影响：`--cpca-radius`、`--cpca-border` 以及 `.cpca` 容器 `gap` 等根变量/布局规则失效，从而表现为卡片直角、块间距缺失。
- 修复：补回注释开头 `/*`，恢复 `.cpca` 根规则的正常解析。
- 验证：CSS 文件错误检查通过（No errors found）。

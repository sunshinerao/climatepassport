# Passport Web Design Alignment 2026-05-20

## 需求解读

- 在正式检查页面可运行性之前，先参考上海气候周网站的字体、字号、视觉风格，对 Climate Passport 页面设计进行修正。
- 修正目标是视觉语法对齐，而不是恢复 SHCW 品牌文案。

## 修改方法

- 先从旧站页面提取视觉基线：中文字体优先级、深色底+渐变光斑、轻纹理背景、高对比卡片、导航与按钮的层级语法。
- 在 passport-web 中优先改全局样式与根布局字体栈，以最小改动覆盖所有页面。
- 保持现有组件结构不变，避免功能回归风险。

## 修改内容

- 更新 `apps/passport-web/app/globals.css`
  - 调整全局设计变量（品牌主色、背景色、描边、阴影）为深色主基调与绿色强调色
  - `body` 改为 Noto Sans SC 优先字体栈，并新增背景网格纹理层
  - 顶栏改为深色磨砂样式，品牌文字与导航改为高对比方案
  - 导航字号与字距改为更接近旧站的信息层级表达（小号、加粗、轻大写）
  - Hero 区渐变风格调整为深色+绿色高光
  - 主次按钮由胶囊改为更克制的圆角矩形，增强旧站风格一致性
  - Footer 深化为旧站一致的深色层级
- 更新 `apps/passport-web/app/layout.tsx`
  - 根布局内联字体栈改为 Noto Sans SC 优先，与全局一致

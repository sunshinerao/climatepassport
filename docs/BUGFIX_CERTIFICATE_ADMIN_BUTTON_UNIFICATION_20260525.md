# 需求解读
证书后台页面里那几组切换按钮不需要再维持独立的 amber/outline 视觉分支。用户希望它们直接和页面里的其他 button 使用同一套基础样式，减少样式偏差和维护复杂度。

# 修改方法
把这几组按钮从专用变体类切回统一的基础按钮类，只保留功能交互，不再依赖活跃态的独立颜色和边框覆盖。这样它们会和页面中其他普通按钮保持一致。

# 修改内容
- 调整 `apps/passport-web/components/certificate-admin-prototype.tsx`。
- 将证书签发、申请审核、验证日志三组切换按钮统一改为 `cpca-btn` 基础类。
- 移除这些按钮上的 amber / outline 变体类与内联颜色覆盖。
- 保持按钮交互逻辑不变，只统一外观表现。
